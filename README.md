# ### More information

NBT Addon is an NBT addon for Minecraft Bedrock Edition, currently in alpha version.

 

How to get items:

To get several NBT items, enter the following command:

 

/function ArmorAndItems

 

Project status:

 This is an alpha version. Features may be incomplete or subject to change.
